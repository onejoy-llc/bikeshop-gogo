# バイクショップGOGO ホームページ

## 起動のしかた
1. ターミナルでこのフォルダを開く
2. `npm start` を実行する
3. ブラウザで http://localhost:3210 を開く（管理画面は http://localhost:3210/admin ）

## 管理画面
- 初回だけ、パスワードを決める画面が出ます（8文字以上）。
- 車両・パーツ・オプション・店舗情報・写真を編集し、画面下の「保存する」を押すとすぐサイトに反映されます。
- フォームから届いたお問い合わせは「お問い合わせ」で確認できます（メール通知はありません）。

## データの場所
- `data/site.json` … サイトの内容すべて
- `data/inquiries.json` … お問い合わせ
- `data/admin.json` … 管理画面のパスワード（暗号化済み）
- `public/uploads/` … 写真

## 公開について
Node.js（18以上）が動くサーバーが必要です。公開時は必ず https で配信し、公開前に管理画面のパスワードを設定してください。
